# Análise da base de dados PRF

## Objetivo

Este projeto tem como objetivo estudar lógica de programação, por meio de Python e SQL, para analisar a base de dados de acidentes da PRF

## Etapas do Projeto:
### Etapa 1: Lógica:
Tem como objetivo estudar e aprender os conceitos de lógica de programação, utilizando a linguagem Python
### Etapa 2: Diagnóstico:
Essa etapa buscou analisar e padronizar a base de dados da Polícia Rodoviária Federal (PRF), primeiro analisando duplicatas, espaços vazios e outros tipos de erros que poderiam ser encontrados na base.
### Etapa 3: Limpeza:
Essa etapa buscou realizar a limpeza da base de dados PRF e analisar os gráficos que podem ser utilizados. Para a limpeza, foi padronizado o texto, os espaços vazios e o tipo de data. Já para os gráficos, foram analisados os gráficos que melhor se encaixariam para cada análise. Para variáveis qualitativas foram utilizados gráficos de barra e gráfico de pizza, já para variáveis quantitativas, foi utilizado o histograma.
### Etapa 4: SQL:
Teve como objetivo aprender e praticar o SQL fazendo consultas e análises por meio do select. Para a prática, foram analisados os estados e municípios com maiores registros de acidente, quais os tipos e causa de acidentes da base, entre outros, além de ter sido feita a padronização dessa tabela padronizando os nomes e espaços vazios
