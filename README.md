# Análise da base de dados PRF

## Objetivo

Este projeto tem como objetivo estudar lógica de programação, por meio de Python e SQL, para analisar a base de dados de acidentes da PRF

## Etapas do Projeto:
### Etapa 1: Lógica:
Tem como objetivo estudar e aprender os conceitos de lógica de programação, utilizando a linguagem Python
### Etapa 2: Diagnóstico:
Essa etapa buscou analisar e padronizar a base de dados da Polícia Rodoviária Federal (PRF)
### Etapa 3: Limpeza:
Essa etapa buscou realizar a limpeza da base de dados PRF e analisar os gráficos que podem ser utilizados.
### Etapa 4: SQL:
Teve como objetivo aprender e praticar o SQL fazendo analises utilizando o Select na base de dados.

## Como rodar os notebooks:
1- Baixe os notebooks
2- Faça login no Google Colab
3- Faça upload do notebook

## Principais aprendizados:
1 - Linguagens de programação focadas em ciência de dados
2 - Variáveis mais relevantes nos índices de acidentes
